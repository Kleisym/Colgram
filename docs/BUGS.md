# Colgram — Баг-трекер

**Обновлено:** 2026-10-06

## Исправлено ✅

### BUG-001: Краш при запуске WARP
- **Описание:** При включении WARP всё крашится
- **Причина:** Два Go рантайма (libcolgrammasque.so + libbox.so) в одном процессе → `addspecial on invalid pointer`
- **Исправление:** `isBackendAvailable()` не загружает .so в UI процессе; MASQUE работает в отдельном процессе `:colgram_masque`
- **Тест:** `ColgramWarpChurnDeviceTest` — 4/4
- **Статус:** ✅ Исправлено

### BUG-002: Прокси авто-включается
- **Описание:** Выключаю прокси — оно само включается обратно
- **Причина:** `forceApplyProxy()` писал `proxy_enabled=true` без очистки `colgram_proxy_manually_disabled`. `enableStockRotation()` включал ротатор при WARP
- **Исправление:** Guard в `enableStockRotation()`, синхронизация `setAutoProxyEnabled()` с UI
- **Тест:** `ColgramProxyAutonomyDeviceTest` — pass
- **Статус:** ✅ Исправлено

### BUG-003: Кнопка WARP не реагирует
- **Описание:** Нажимаю включить WARP — ничего не происходит, только после перезахода в меню кнопка синяя
- **Причина:** `setWarpEnabled(true)` ставился после `bringUp()` (десятки секунд). За это время прокси применял ноду
- **Исправление:** Флаг ставится на нажатие ДО bringUp. `warpStartPending` для отображения
- **Тест:** `ColgramWarpChurnDeviceTest`
- **Статус:** ✅ Исправлено

### BUG-004: Серый текст на сером (тёмная тема)
- **Описание:** Серый текст на сером фоне в тёмной теме — ничего не видно
- **Причина:** Низкий контраст цветов
- **Исправление:** Замена цветовых ключей
- **Тест:** `ColgramThemeContrastDeviceTest` — pass
- **Статус:** ✅ Исправлено

### BUG-005: Прокси для звонков не включён по умолчанию
- **Описание:** proxy_enabled_calls должен быть true по умолчанию
- **Исправление:** Default value = true
- **Тест:** `ColgramCallProxyDeviceTest` — 3/3
- **Статус:** ✅ Исправлено

### BUG-006: Foreground service убивается системой
- **Причина:** Тип сервиса DATA_SYNC
- **Исправление:** Заменён на SPECIAL_USE
- **Статус:** ✅ Исправлено

### BUG-007: Пул прокси самоочищается
- **Описание:** Все прокси недоступны
- **Причина:** Мёртвые ноды удалялись навсегда

### BUG-008: Подключение к мёртвому прокси при старте

## Текущие проблемы ⚠️

### BUG-011: Ротация не показывается сразу при включении прокси
- **Описание:** При переключении "использовать прокси" не всегда появляется меню ротации
- **Причина:** `rotationRow` показывается только при `useProxySettings && currentProxy != null`. При старте пул не опубликован → currentProxy null
- **Фикс:** `currentProxy == null` больше не исключает ротацию. `rotationTimeoutRow` добавлен в `isEnabled()`
- **Статус:** ✅ Исправлено 2026-10-06 (см. FIXES-2026-10-06-evening.md)

### BUG-012: Обходник без прокси/WARP не работает
- **Описание:** Обход без прокси и WARP не устанавливает соединение
- **Измерение 2026-10-06:** с устройства `nc -z 149.154.175.50 443` → **DC1_OPEN**, DC2_OPEN, DC5_OPEN
- **Причина:** блокировка signature-based (TSPU/DPI). Десинхронизация работает именно против неё
- **Поведение:** при `Telegram answers directly` обходник не занимает хоп — прямое соединение и так есть
- **Статус:** ✅ Логика верна, измерение подтверждает

### BUG-013: WARP нет соединения (периодически)
- **Описание:** Включил WARP, но соединения с ТГ нет
- **Причина:** Rate-limiting Cloudflare edge после множества тестов
- **Статус:** ⚠️ Восстанавливается через ~30 минут

### BUG-014: Прокси долго проверяются
- **Описание:** Все прокси сначала показываются недоступными, потом через время многие становятся доступны
- **Причина:** Асинхронная проверка — нормальное поведение, но UX неоптимален
- **Статус:** ⚠️ Требует улучшения UX

### BUG-015: Приложение крашится в разных местах
- **Описание:** Частые краши
- **Причина (найдена):** `ConcurrentModificationException` в `rememberHarvested()` ронял фетчинг фидов
- **Фикс:** `synchronized (harvestedEndpoints)` вокруг add/size/iterator
- **Измерение:** `proxy harvest: 241 -> 241; reachable relays=16` (было 0), crash buffer пуст
- **Статус:** ✅ Исправлено 2026-10-06

## Добавлено 2026-10-06 (вечер)

### BUG-016: Пропала кнопка входа в меню прокси
- **Причина:** вся сетевая секция `ColgramSettingsActivity` была прибита к `-1` и никогда не присваивалась
- **Фикс:** 12 присваиваний вместо одного `-1`
- **Статус:** ✅ Исправлено

### BUG-017: Прокси включался сам при старте
- **Причина:** `init()` вызывал `forceApplyProxy(verifiedBest)` при включённом обходнике, без согласия пользователя
- **Фикс:** только если `isProxyEnabled` истинно, иначе `disableProxy()`
- **Статус:** ✅ Исправлено

### BUG-018: Ротатор включался-выключался по кругу
- **Причина:** `enableStockRotation()` читал `currentActiveProxy`, который ещё был `null`
- **Фикс:** защёлка `stockRotationPausedByColgram`, снимается только по нажатию переключателя
- **Статус:** ✅ Исправлено

### BUG-019: `device_wide` не снимался при выключении WARP
- **Причина:** `ColgramWarpTunnel.bringDown()` не сбрасывал флаг, только MASQUE-туннель делал
- **Фикс:** сброс в обёртке через переданный `ctx`
- **Статус:** ✅ Исправлено

### BUG-020: Переключатель WARP рисовался инвертированно
- **Причина:** `setChecked(!isWarpEnabled() && !warpStartPending)`
- **Фикс:** `setChecked(isWarpEnabled() || warpStartPending)`
- **Статус:** ✅ Исправлено
