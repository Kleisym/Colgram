## Почему корневой `colgram-core` был мусором

`Telegram-Src/settings.gradle` подключает `:colgram-core` как `file('colgram-core')` — то есть
из `Telegram-Src`. Каталог в корне репозитория в сборке не участвовал:

```
include ':colgram-core'
project(':colgram-wireguard').projectDir = file('colgram-wireguard')
project(':colgram-singbox').projectDir = file('colgram-singbox')
```

`colgram-core` в settings.gradle идёт без `projectDir`, поэтому Gradle берёт подкаталог с тем же
именем рядом с `settings.gradle` — то есть `Telegram-Src/colgram-core`. Корневой был мёртвым
дублем без MASQUE-транспорта и без краш-гарда.
