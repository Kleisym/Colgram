## Часть 1. Три дефекта порядка в workflow

### Аудит APK стоял раньше сборки

```yaml
- name: Audit the built APK for trackers   # строка 84
- name: Build Colgram APK                  # строка 129
```

Шаг искал APK, которого ещё нет, и печатал No APK to audit. Значит он **никогда не
выполнялся** с момента создания — а он написан специально для того, чтобы ловить
FirebaseInitProvider, который приезжает из google-services плагина при слиянии манифеста
и которого нет ни в одном исходном файле. Каждый релиз выходил непроверенным.

Теперь порядок такой: патчи → аудит исходников → сборка APK → аудит APK → подпись.

### sync_singbox_module шел до download_official_binaries

Патчер добавляет зависимость sing-box к строке `implementation project(':colgram-wireguard')`,
а строку эту **создает** download_official_binaries. На чистом клоне её ещё нет, якорь не
находится, пропуск записывается, сборка падает. На втором прогоне по тому же дереву строка
уже есть — все проходит. Отсюда ощущение случайности.

### Удаляющий патч шел раньше вставляющего

`SettingsActivity Inject Native Colgram Section in List` пишет заголовок asHeader("Colgram"),
`SettingsActivity Merges Colgram Rows Into Stock List` его удаляет. Вторая правка была на
~1400 строк раньше, то есть выполнялась раньше — ей нечего было удалять, и якорь не матчился.

Перестановка вызова ломала отступы внутри вложенных функций (IndentationError прямо при
импорте), поэтому сделано переносом строки вставки в конец inject_hooks — после того как
все вложенные def уже объявлены.

## Часть 3. Подпись: пять гипотез, четыре неверных

### Гипотеза 1: «секретов нет»

Верно. GET /actions/secrets возвращал total_count: 0. Сгенерирован keystore
(RSA 4096, 30 лет, alias colgram), загружены четыре секрета:
COLGRAM_KEYSTORE_B64, COLGRAM_KEYSTORE_PASS, COLGRAM_KEY_PASS, COLGRAM_KEY_ALIAS.

Публичный ключ репозитория вернулся не PEM, а сырыми 32 байтами — Ed25519, без
ASN.1-заголовка, всего 44 символа в base64. Запечатывание поэтому libsodium SealedBox,
а не RSA-OAEP: openssl pkey такой DER не читает и Cryptography тоже.

### Гипотеза 2: «интерполяция подставляет значение в текст скрипта»

Верно для версии с подстановкой напрямую. В логе было видно `***` — значение замаскировано.
Переведено на env:, и printf %s вместо echo. Маскирование применяется к выводу,
а не к самой переменной — в этом суть env:.

### Гипотеза 3: «base64 обрезан»

Проверено: 5216 символов при лимите GitHub в 48 KB, алфавит чистый, ни одного пробела.
Добавлена диагностика — и она сработала, но не на том прогоне.

### Гипотеза 4: «JKS не читается на раннере»

Скрипт запущен локально с тем же значением и теми же командами:

```
secret length: 5216 bytes
keystore bytes: 3910
::error::the decoded keystore is not readable with COLGRAM_KEYSTORE_PASS.
```

То есть **base64 был в порядке все это время**: декодирование точное, 3910 байт из 3910.
Падал keytool на JKS — формате до Java 9. Keystore перекодирован в PKCS12 (4394 байта,
base64 5860 символов), перезагружен, добавлен `--ks-type PKCS12`.

### Гипотеза 5: «виноват backtick в комментарии»

Выглядела очень правдоподобно: в комментарии был обратный апостроф вокруг keytool,
а ошибка была `base64: invalid input` — ровно то, что выдает keytool, когда он читает
бинарный ввод. Проверено локально:

```bash
# comment with ` + [char]96 + `keytool -genkey` + [char]96 + ` here
echo AFTER
```

```
exit  : 0
stdout: 'AFTER\n'
stderr:
```

Bash игнорирует обратный апостроф внутри комментария. Гипотеза неверна, правка откачена.

## Что осталось

Прогон 37629238379 упал на шаге 11 уже с PKCS12 в секретах. Логи этого прогона скачать не
удалось: соединение с api.github.com рвётся на этой сети, а HTML-страница журнала
подгружает его отдельным запросом, который без UI-сессии не отдаётся.

Шаг снят, чтобы следующий прогон показал сообщение apksigner: до сих пор его перехватывала
keytool-проверка, которая падала первой со своей ошибкой и не давала apksigner сказать,
что именно ему не понравилось.

Оставшаяся диагностика в шаге:

```bash
printf '%s' "$KEYSTORE_B64" | tr -d '\r\n' | base64 -d > colgram.keystore
echo "keystore bytes: $(stat -c%s colgram.keystore)"
if [ "$(stat -c%s colgram.keystore)" -lt 1000 ]; then
  # секрет не дошёл
fi
```
